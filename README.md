# Truth Index Systems one-page website

Static landing page for `truthindexsystems.co.uk`.

## Files
- `index.html` — landing page
- `styles.css` — styling based on the Truth Index product theme
- `assets/dashboard-mock.svg` — mock dashboard image with made-up data
- `assets/receipt-mock.svg` — mock receipt image with made-up data

## Deploy
Upload the folder contents to any static host, for example Netlify, Vercel, Cloudflare Pages, GitHub Pages, or your domain provider's web hosting.

## Update before launch
Replace `hello@truthindexsystems.co.uk` in `index.html` with your real contact email when ready.
